EnterpriseDoc AI REST API & Services Specification (v2.0)

This document details the public and internal RESTful API interfaces provided by EnterpriseDoc AI. All requests must be transmitted over encrypted TLS 1.3 channels and use JSON request/response encoding.

1. Authentication Endpoints

Authentication utilizes salted bcrypt hashing and JSON Web Tokens (JWT) for secure session management across web and mobile clients.

POST /api/v1/auth/login

Authenticates an employee or administrator and returns an access token.

POST /api/v1/auth/login
Content-Type: application/json

{
    "username": "admin",
    "password": "admin123"
}

Response (HTTP 200 OK):

{
    "status": "success",
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "token_type": "bearer",
    "user": {
        "id": 1,
        "username": "admin",
        "role": "admin"
    }
}

2. Document Management & Ingestion Endpoints

Manage enterprise documentation repository files including PDF manuals, HTML articles, Markdown guides, and raw text policies.

POST /api/v1/documents/upload

Uploads and indexes an enterprise document. Generates SHA-256 fingerprint for deduplication. Rejects duplicate files with HTTP 409 Conflict.

GET /api/v1/documents

Retrieves all indexed documents in the database along with total chunk counts, file sizes, and upload timestamps.

DELETE /api/v1/documents/{document_id}

Permanently deletes a document from SQLite metadata storage and removes all corresponding vector embeddings from ChromaDB.

3. Hybrid RAG Query & Question Answering

The conversational Q&A endpoint combines vector similarity search and BM25 keyword matching to retrieve relevant passages, detect contradictions, and synthesize grounded answers.

POST /api/v1/chat/query

Content-Type: application/json
